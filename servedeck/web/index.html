Live data. Capacity comes from the running engine where it can: the KV size a server reports on /metrics is labelled measured, and only a model that has never booted here falls back to the per-architecture estimated calculator. Figures are never carried over from a different model.

Stopping and restarting run through Servedeck's supervisor. It shells out to the same launcher scripts a terminal would, so a dashboard launch and a CLI launch build the same server.
